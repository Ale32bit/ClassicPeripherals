# <center><img alt="Classic Peripherals" src="assets/logo.png" width="256"></center>

Welcome to the **ClassicPeripherals** wiki!

Classic Peripherals is an addon for CC: Tweaked implementing various kinds of peripherals and tweaks to the mod, some of
which are inspired by older and no longer maintained addons.

## Download & install

[![](assets/buttons/modrinth.svg)](https://modrinth.com/mod/classicperipherals)
[![](assets/buttons/curseforge.svg)](https://www.curseforge.com/minecraft/mc-mods/classic-peripherals)

Requires [CC: Tweaked <img alt="cc: tweaked" width="24" src="https://cdn.modrinth.com/data/gu7yAYhd/icon.png">](https://modrinth.com/mod/cc-tweaked).
